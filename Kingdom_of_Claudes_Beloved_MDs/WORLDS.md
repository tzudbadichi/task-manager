# ערכות נושא לתצוגת הדמויות (עולמות)

## מה הרכיב עושה

תצוגת הדמויות (ראו `PEOPLE_VIEW.md`) יכולה להיות משרד, או אחד מ-15 עולמות מצוירים: טירת קוסמים, ארץ התיכונה, ספינת פיראטים, תחנת חלל ועוד. לכל עולם יש:
- **תמונת רקע מצוירת**: פנורמה (SVG) שמחליפה את הקיר, ואדמה משלו (אריח SVG חוזר).
- **דמויות "משם"**: 5-6 טיפוסים לכל עולם, כמו הוביטים, גמדים ואלפים, או טבח ראשי, מלצר ושוטף כלים. כל טיפוס בכמה וריאציות.
- **ריהוט ושתי תחנות עבודה** בסגנון העולם.
- **מאגר של כ-100 משפטים**.
- **צבע מבטא** לכל האפליקציה.

המשרד הוא ברירת המחדל. הבחירה נעשית בבורר "ערכת נושא" בסרגל של תצוגת הדמויות, או בהגדרות ("ערכת נושא לדמויות"), ונשמרת במכשיר (`ui.display.world`).

**מקוריות:** כל הציורים והמשפטים מקוריים ומעבירים את התחושה של הז'אנר. אין בהם העתקה של דמויות, תלבושות מזוהות, סמלים, לוגואים, שמות או תמונות מספרים, סרטים או סדרות. לדוגמה, "המרגלים הצעירים" מתרחש בבסיס סודי בהרי סקוטלנד, אבל הדמויות אינן הדמויות מהספרים. היצורים של "מאמני יצורים" מקוריים, ולטאת האש בכוונה לא כתומה. שמות היצירות מופיעים רק בשם הערכה בבורר. המשפטים מנוסחים בלשון שמתאימה לכל מגדר.

## מבנה עולם (נתונים)

```js
export default Object.freeze({
  key: 'middle-earth',                               // מפתח ב-ui.display.world
  label: 'ארץ התיכונה (שר הטבעות)',                  // השם בבוררים ובכותרת
  accent: { light: '#15803d', dark: '#86efac' },     // null במשרד
  stations: { desk: 'maptable', craft: 'anvil' },    // null במשרד
  scene: { wallScale: 1.6 },                         // null במשרד: כמה הקיר גבוה יותר
  cast: { archetypes: [{ key: 'hobbit', weight: 32, kind: 'hobbit', size: 0.8 }, ...] },
  lines: { openers, replies, smallTalk, poses, myDay, sameCategory, listenerBusy, greetingReply },
});
```

השדות של צוות (`cast.archetypes`):
- `key`: שם הפונקציה ב-`world-art/<key>.js`.
- `weight`: כמה הטיפוס נפוץ.
- `kind`: נכתב ל-`data-kind` של הדמות. `ghost`, `merfolk` ו-`cloud` מרחפים במקום לפסוע (CSS).
- `size`: גודל, בין 0.6 ל-1.5.

## ציור הדמויות

**המראה:**
- `lookOf(taskId, cast)` (people-model.js) בוחר טיפוס לפי המשקלות ונותן `seed`.
- הטיפוס (`archetypes[key](look)` בקובץ הציור) בוחר מה-seed את הווריאציות שלו דרך `rngOf(look)`: צבע עור ושיער, בגדים, כובע, חפץ ביד.
- לכן אותה משימה מקבלת תמיד אותה דמות, ושתי משימות מאותו טיפוס נראות שונות.

**החלקים:** הטיפוס מחזיר אובייקט חלקים, ו-`composeFigure` מרכיב אותו לשלד שה-CSS מניע:

| חלק | מה |
|-----|-----|
| `behind` | מאחורי הכל: גלימה, אשפה לחצים, זנב |
| `legBack`, `legFront` | הרגליים, מסתובבות סביב הירכיים (41,88) / (51,88) |
| `armBack`, `armFront` | הזרועות, מסתובבות סביב הכתפיים (37,62) / (55,62) |
| `held` | החפץ ביד האחורית |
| `cape` | בין הזרוע האחורית לגוף |
| `torso`, `overTorso` | הגוף והבגדים |
| `head` | `back`, `base`, `features`, `eyes`, `brows`, `beforeMouth`, `mouth`, `front`, `eyewear`, `hat`, `cheeks`; מסתובב סביב הצוואר (46,55) |
| `front` | מעל הכל |

**מה `composeFigure` מוסיף לכל דמות:**
- **הפנים לפי מצב הרוח:** עיניים, גבות ופה.
- **סימני מצב:** שעון חול, z-z-z, ניצוצות, טיפת זיעה, בועת מחשבה.
- **הכוס** בהפסקת קפה.
- **אביזרי חג:** כובע החג מחליף את `hat`, וחפץ החג מחליף את `held`.

**אבני הבניין של הערכה** (`figure-kit.js`), בסגנון מצויר עם קו מתאר:
- צורות: `shape`, `blob`, `dot`, `box`, `stroke`, `shade`, `limb`.
- גוף: `arm` (שרוול צמוד, מופשל, קצר, חשוף, רחב או נפוח), `leg` (מכנסיים ארוכים או עד הברך; נעליים, מגפיים, מגפיים גבוהים, יחף, כפות רגליים שעירות או סנדלים), `torsoPath`, `longGarmentPath`, `belt`, `buttons`, `cloakBack`, `cloakFront`.
- ראש: `headBase` (אוזניים עגולות, מחודדות קטנות, מחודדות או ארוכות), `nose`, `HAIR`, `BEARD`.
- בחירה מה-seed: `rngOf`, `pick`, `pickWeighted`.

**צבע הקטגוריה:** כל טיפוס לובש אותו על בגד בולט, דרך המילוי `'cat'`, `'cat-dark'` או `'cat-light'`. הם נצבעים מ-`--cat-color` עם קו מתאר (styles.css).

**כללי ציור:**
- הדמויות מוצגות ברוחב של כ-70 פיקסלים, ולכן צללית חזקה וחפץ מזוהה עדיפים על פרטים קטנים.
- לא שמים `transform` על צורה שיש לה class של אנימציה, כי ה-CSS קובע לה `transform-box`. במקום זה עוטפים אותה בקבוצה.

## הסצנה

- **הקיר:** `scene.wallScale` מגביה את הקיר (`computeWorldLayout({ wallScale })`; בנייד עד פי 1.4).
- **הפנורמה:**
  - people-view.js מוסיף לחדר `.world-backdrop`, ו-worlds.css מציב בו את הפנורמה ב-`cover`, מעוגנת למטה במרכז.
  - במחשב רואים כמעט את כל רוחבה, ובטלפון את המרכז (בערך x בין 750 ל-1650). לכן הדברים המזוהים במרכז.
  - 34 הפיקסלים התחתונים נמוגים (`mask-image`) אל האדמה, ותחתית הציור בצבע האדמה.
- **פריטי הקיר:** החלון, התמונה והשעון של המשרד לא מוצגים בסצנה.
- **ריהוט ותחנות:** כל עולם מצייר את כל הריהוט שלו (דלת, מדף, ספה, שטיח, עמדת שתייה, מים, עציצים), במידות `ART` של world-layout.js, ואת שתי התחנות שלו (viewBox `68 20 72 96`).
- **אנימציות:**
  - classes של אנימציה בציורים: `flame`, `p-glow`, `p-spark`, `p-bubble`, `p-holo`, `p-blink-led`, `p-sway`, `p-rain`, `p-pour`, `p-wobble`, `p-dial`.
  - תחנה "חיה" (להבות, ניצוצות, בועות) רק כשהמשימה בעבודה, כמו במשרד, וזוהרים על דמויות לא מהבהבים. כל צורה מונפשת מציירת מחדש את כל ה-SVG שלה, וכך גם 48 דמויות נשארות חלקות.
- **הפנורמות:** קבצים סטטיים בלי אנימציה, סקריפטים, תמונות או הפניות חיצוניות. הן נטענות רק כשהעולם נבחר (בערך 20-75KB כל אחת).

## צבע מבטא וחגים

- `applyWorld()` (app.js) קובע `html[data-world]` ואת `--world-accent` / `--world-accent-dark` (CSSOM, מותר תחת ה-CSP).
- הכללים `:root[data-world]` נמצאים לפני כללי החגים, ולכן בתקופת חג צבע החג גובר.
- במשרד אין צבע מבטא.
- אביזרי החג של הדמויות נשמרים בכל העולמות.
- לפנורמות אין גרסה כהה ואין שעות ביום. רק צבע המבטא עובר לגרסה הכהה.

## בדיקות

`tests/worlds.test.js`:
- **הרשימה:** מפתחות ושמות ייחודיים, המשרד ראשון, `getWorld` חוזר למשרד, ו-`worldStationFor` עובד.
- **נתונים וקבצים, לכל עולם מצויר:**
  - צבע מבטא חוקי ו-`scene.wallScale` בטווח.
  - שתי התחנות קיימות בציור, וכל הריהוט קיים.
  - הפנורמה והאדמה קיימות, במידות הנכונות, בלי סקריפטים, תמונות, handlers או הפניות חיצוניות, ו-worlds.css משתמש בהן.
- **ציור:**
  - כל טיפוס מצויר ב-24 seeds ובכל מצבי הרוח (חלקם עם כובע חג), וגם כל רהיט וכל תחנה.
  - הציור נעשה ב-DOM מדומה (`tests/fixtures/fake-svg-dom.js`), והבדיקה מוודאת שאין NaN, undefined או null באף מאפיין, שכל צבע (`fill`, `stroke`) הוא צבע תקין וכל קואורדינטה היא מספר. כך נתפס, למשל, צבע קטגוריה שהועבר ל-`darker()`. בערכה, `toneLine` מצייר קו כהה או בהיר יותר גם מעל צבע הקטגוריה.
- **משפטים:**
  - אותם מצבי רוח ותנוחות כמו במשרד, לפחות 90 משפטים בלי חזרות.
  - עברית בלבד, בלי אותיות לטיניות ובלי אימוג'י, עד 60 תווים.
  - כל משפט משתמש רק במצייני המקום שמתאימים למקום שבו הוא נאמר.

### דף הגלריה (פיתוח)

מגישים את שורש המאגר (`python -m http.server 8140 --directory <repo>`) ופותחים `/tests/fixtures/world-gallery.html?world=<key>`.

הדף מציג:
- את הפנורמה כולה.
- הדמיה של חדר במחשב ובטלפון.
- את האדמה חוזרת.
- כל טיפוס ב-8 וריאציות.
- טיפוס אחד בכל התנוחות.
- את הריהוט והתחנות בגדול.

## הוספת עולם

1. **נתונים:** `src/js/worlds/<key>.js` לפי המבנה, ולהוסיף אותו ל-`WORLDS` ב-index.js.
2. **ציור:** `src/js/world-art/<key>.js` (טיפוסים, ריהוט, תחנות), ולהוסיף אותו ל-world-art/index.js.
3. **תמונות:** `src/img/worlds/<key>/backdrop.svg` ו-`floor.svg`, ושתי שורות ב-worlds.css (האדמה עם צבע בסיס, והפנורמה).
4. **בדיקה:** לבדוק בגלריה ובאפליקציה, ולהריץ `npm test`.
