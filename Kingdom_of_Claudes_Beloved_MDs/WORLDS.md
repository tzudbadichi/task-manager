# ערכות נושא לתצוגת הדמויות (עולמות)

## מה הרכיב עושה

תצוגת הדמויות (ראו `PEOPLE_VIEW.md`) יכולה להיות משרד, או אחד מ-15 עולמות: טירת קוסמים, ספינת פיראטים, תחנת חלל וכו'. כל עולם מגדיר:
- **חדר** משלו: צבעי קיר ורצפה ודוגמה.
- **ריהוט**: חלון, דלת, מקום ישיבה, עמדת שתייה, עציץ, מדף ותמונה.
- **שתי תחנות עבודה**: "שולחן" ו"מלאכה".
- **צוות דמויות**: סוגים, לבוש, כובעים וחפץ ביד.
- **מאגר של כ-100 משפטים** שהדמויות אומרות.

העולם גם צובע את צבע המבטא של כל האפליקציה (כפתורים, פוקוס). המשרד הוא ברירת המחדל.

הבחירה נעשית בבורר "ערכת נושא" בסרגל של תצוגת הדמויות, או בהגדרות ("ערכת נושא לדמויות"). היא נשמרת במכשיר (`ui.display.world`).

כל המשפטים מקוריים, נכתבו לאפליקציה ונוסחו בלשון שמתאימה לכל מגדר. אין בהם ציטוטים ושמות של דמויות או מקומות מספרים, סרטים או סדרות. שמות היצירות מופיעים רק בשם הערכה בבורר.

## קבצים

- `src/js/worlds/<key>.js` - עולם אחד: נתונים בלבד (`Object.freeze`).
- `src/js/worlds/index.js`:
  - `WORLDS`: הרשימה, בסדר שמוצג בבוררים.
  - `DEFAULT_WORLD_KEY`, `WORLD_KEYS`.
  - `getWorld(key)`: מחזיר את המשרד כשהמפתח לא מוכר.
  - `worldStationFor(world, activity)`.
- `src/js/art-worlds.js`:
  - הציורים של הריהוט והתחנות של העולמות.
  - `worldDecorParts(kind, variant)`, `createWorldStationArt(stationKey)`.
  - `WORLD_SCENERY_KEYS`: כל המפתחות הקיימים.
- `src/js/svg-kit.js` - עזרי SVG משותפים ל-art.js ול-art-worlds.js: `svg`, `rect`, `circle`, `path`, `mixColor`, `lighter`/`darker` ועוד.
- `src/js/art.js`:
  - חלקי הדמויות של כל העולמות (`CHARACTER_PARTS`).
  - `createDecorArt(kind, size, { variant, theme })`.
  - `createStationArt(activity, { done, worldStation })`.
  - `OFFICE_SCENERY_KEYS`.
- `src/css/styles.css`:
  - בפרק "People view": "Themed worlds" (חדר לכל `data-room`, צבעי השטיח, בורר הערכה, אנימציות הריהוט, ריחוף רוחות).
  - בראש הקובץ: `:root[data-world]`.
- `src/js/app.js`: `currentWorld`, `applyWorld`, הפעולה `set-world`.
- `tests/worlds.test.js`.

## מבנה עולם

```js
export default Object.freeze({
  key: 'pirates',                 // מפתח ב-ui.display.world
  label: 'ספינת פיראטים',         // השם בבוררים ובכותרת המשרד
  room: 'ship',                   // data-room על המשרד - החדר ב-CSS
  accent: { light: '#9a3412', dark: '#fdba74' },   // null במשרד
  decor: { window, door, sofa, coffee, cooler, plant, shelf, picture },   // מפתח ציור לכל רהיט
  stations: { desk: 'chest', craft: 'cannon' },    // null במשרד
  cast: { kinds, outfits, headwear, eyewear, held }, // טבלאות משקל [ערך, משקל]
  lines: { openers, replies, smallTalk, poses, myDay, sameCategory, listenerBusy, greetingReply },
});
```

### ריהוט (`decor`)

לכל סוג רהיט יש מפתח ציור. המפתח יכול להיות של המשרד (`OFFICE_SCENERY_KEYS`: `sky`, `office`, `sofa`, `coffee`, `cooler`, `books`, `art`, `fern`/`snake`) או של עולם (`WORLD_SCENERY_KEYS` ב-art-worlds.js). דוגמאות:
- **חלון**: ויטראז', גבעות, חלל, ים, קו רקיע, ניאון, מפת עולם.
- **דלת**: טירה, דלת עגולה, תא לחץ, ספינה, דלתות סלון, כספת.
- **מקום ישיבה**: ערסל, פופים, ערימות חציר.

ציורים שזזים מקבלים classes שה-CSS מניע: להבות, בועות, הבהובי נורות, הולוגרמה, גשם, נדנוד צמחים.

### תחנות (`stations`)

בעולם יש שתי תחנות. פעילות "ידנית" עובדת בתחנת המלאכה (`craft`), וכל השאר בתחנת השולחן (`desk`). הפעילויות הידניות הן עיצוב, תיקון, ניקיון, ספורט, משלוח, קניות ונסיעה. הדוגמאות כאן הן פירוש של המפתחות לעברית:
- **קוסמים**: עמדת קריאה וקלחת.
- **פיראטים**: תיבת אוצר ותותח.

הדמות עובדת בתחנה בתנוחת עבודה כללית (`data-activity="world"`), בלי חפצי הפעילות של המשרד, כמו טלפון או מטאטא. במשרד התחנה נקבעת לפי הפעילות, כמו קודם.

### צוות (`cast`)

`lookOf(taskId, cast)` (people-model.js) מגריל מהטבלאות של העולם. אותה משימה מקבלת תמיד אותה דמות בתוך העולם.
- טבלה חסרה (כובע, משקפיים, חפץ) פירושה ברירת המחדל של המשרד.
- `kinds` ו-`outfits` חובה.

חלקים שנוספו לעולמות (הכל ב-art.js):

| חלק | מה יש |
|-----|------|
| סוגים | אלף (אוזן מחודדת, גוף דק), גמד (נמוך, רחב, זקן ענק), בן כפר נמוך (יחף), בת/בן ים (זנב), ינשוף, רוח רפאים (מרחפת, בלי רגליים), עץ (גוף קליפה), תוכי, תמנון (זרועות), דג, צב (שריון), דינוזאור (זנב), סוס, דרואיד (גוף מתכת), יטי, יצור קטן ומקורי (פרוותי) |
| לבוש | גלימה, שריון, חליפת חלל, מעיל ארוך, שכמייה, סינר, טוגה, מעיל מרגלים, בגדי שף, טוניקה, בגדי ספארי, שריף, סרבל, ניאון זוהר |
| כובעים | כובע קוסם, קסדה, בועת חלל, כובע פיראטים, בנדנה, מסכה, כובע שף, זר דפנה, כובע בוקרים, כובע ספארי, משקף עתידני, ברדס, מטפחת, אוזניית סוכן |
| משקפיים | רטייה, משקפי מגן |
| ביד | שרביט, מטה, חרב, גרזן, חרב אור, קלשון, מרית, לאסו, מגילה, גאדג'ט, ברק, רשת, את חפירה |

הלבוש תמיד בצבע הקטגוריה, ואביזר החג (בתקופת חג) גובר על החפץ ביד. רוח רפאים מרחפת למעלה ולמטה במקום לפסוע (`ghost-float` ב-CSS). כל השאר משתמשים באותן תנוחות כמו במשרד.

### משפטים (`lines`)

| שדה | מתי נאמר | מצייני מקום |
|-----|----------|--------------|
| `openers[mood]` (7 מצבי רוח x 4) | הדמות מדברת על המשימה שלה | `{sub}`, `{task}`, `{done}`, `{total}`, `{elapsed}`, `{idle}` |
| `replies[mood]` (7 x 4) | תשובה של מי שמקשיב | כמו למעלה (ממולא לפי הדובר) |
| `smallTalk` (8 זוגות) | שיחת חולין | אין |
| `poses[pose]` (8 תנוחות x 3) | הערה על מה שהדמות עושה עכשיו | כמו `openers` |
| `myDay` | משימה ב"היום שלי" | `{sub}` |
| `sameCategory` | שתי דמויות מאותה קטגוריה | `{category}` (חובה) |
| `listenerBusy` | המקשיב מספר במה הוא תקוע | `{sub}` (חובה, של המקשיב) |
| `greetingReply` | תשובה לברכת חג | `{greeting}` (חובה) |

`LINE_PLACEHOLDERS` (people-model.js) הוא רשימת מצייני המקום המותרים. `composePoseLine`, `composeMonologue` ו-`composeConversation` מקבלים `{ lines }`, ובלעדיו נבחרים המשפטים של המשרד.

## איך זה מוצג

- **המשרד** (`people-view.js`):
  - `update(personas, { world, ... })` מקבל את העולם.
  - כשהעולם מתחלף, השיחות נגמרות, והמשרד, הריהוט והתחנות נבנים מחדש. מפתח הפריסה והחתימות כוללים את מפתח העולם.
  - החדר מקבל `data-room` ו-`data-world`.
  - הכותרת בסרגל היא שם העולם, וליד כפתור המסך המלא יש בורר.
- **הדמויות** (`buildPersona(..., { world })`):
  - המראה נלקח מהצוות של העולם.
  - `persona.worldKey` הוא חלק מחתימת הדמות, ולכן היא מצוירת מחדש כשהעולם מתחלף.
- **צבע מבטא**:
  - `applyWorld()` (app.js) קובע `html[data-world]` ואת המשתנים `--world-accent` / `--world-accent-dark` (CSSOM, מותר תחת ה-CSP).
  - הכללים `:root[data-world]` נמצאים לפני כללי החגים, ולכן בתקופת חג צבע החג גובר.
  - במשרד אין צבע מבטא, והתכונות מוסרות.
- **חגים**:
  - אביזרי החג של הדמויות נשמרים בכל העולמות.
  - צבע הקיר של החג חל רק על המשרד, כי לעולמות יש קיר משלהם.
- **מצב כהה**: לחדרים של העולמות יש צבעים משלהם, ולכן הם לא משתנים במצב כהה. צבע המבטא כן עובר לגרסה הכהה.

## בדיקות

`tests/worlds.test.js`:
- מפתחות ושמות ייחודיים, והמשרד ראשון.
- `getWorld` חוזר למשרד, ו-`worldStationFor` עובד.
- לכל עולם:
  - חדר שקיים ב-styles.css, צבע מבטא חוקי.
  - מפתחות ריהוט ותחנות שקיימים בציורים.
  - צוות שמשתמש רק בחלקים ש-art.js יודע לצייר.
  - אותם מצבי רוח ותנוחות כמו במשרד, לפחות 90 משפטים בלי חזרות.
  - המשפטים בעברית בלבד (בלי אותיות לטיניות ובלי אימוג'י), עד 60 תווים.
  - כל משפט משתמש רק במצייני המקום שמתאימים למקום שבו הוא נאמר.

## הוספת עולם

1. יוצרים `src/js/worlds/<key>.js` לפי המבנה, ומוסיפים אותו ל-`WORLDS` ב-index.js.
2. מוסיפים חדר ב-styles.css (`.people-world[data-room="..."]`).
3. ריהוט או תחנה חדשים מוסיפים ל-art-worlds.js, וחלקי דמות חדשים ל-art.js.
4. מריצים `npm test`.
