חיבור הלוח לאייג'נטים שעובדים על מחשב הפיתוח: Claude Code עם חשבון העבודה, ו-Codex עם החשבון האישי. מסמנים כל שלב שהושלם; ההתקדמות נשמרת בדפדפן.

איך זה עובד: בלוח משייכים משימת פיתוח לפרויקט, ולכל תת-משימה יש כפתור "לאייג'נט". ההודעה נכנסת לתור בענן. הראנר, תוכנית קטנה שרצה ברקע על מחשב העבודה, לוקח אותה, מריץ את האייג'נט בתיקייה ובענף נפרדים למשימה, ומחזיר את התשובה ללוח. בזמן שהאייג'נט עובד תת-המשימה "ממתין לתגובה", וכשהוא מסיים היא "בעבודה אצלי". אפשר לענות לו מהלוח, גם מהנייד.
  • הפרדה בין עבודה לאישי: לכל פרופיל יש רשימת תיקיות וחשבון משלו, והראנר לא עולה אם תיקייה שייכת לשניהם. משימה של פרויקט עבודה תמיד רצה עם Claude בחשבון העבודה. ההפרדה קובעת איפה האייג'נט עובד, לא מה הוא יכול לקרוא בדיסק. להפרדה מלאה צריך להריץ את הפרופיל האישי תחת משתמש Windows נפרד.
  • מה עולה לענן: בפרויקטים של העבודה עולה רק סיכום קצר במילים, בלי קוד. הפירוט המלא נשאר בלוג המקומי במחשב.
  • בלי push: האייג'נט לא דוחף ולא ממזג. עוברים על הענף ב-VS Code וממזגים לבד.
