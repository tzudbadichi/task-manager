# ניהול משימות

מנהל משימות אישי בעברית: משימות בריבועים שאפשר לגרור ולסדר, תתי משימות, ארבעה סטטוסים, קטגוריות צבעוניות, והתחברות שמסנכרנת בין המחשב לנייד.

**כתובת:** https://tzudbadichi.github.io/task-manager/

## מה יש בו

- **גריד ריבועים** - כל משימה היא ריבוע: הפס העליון בצבע הקטגוריה, והרקע והמסגרת בצבע הסטטוס. בריבוע תצוגה מקדימה של תתי המשימות, וליד כל אחת תיבת סימון וכפתור קטן לשינוי הסטטוס שלה - בלי לפתוח את המשימה. לחיצה על שאר הריבוע פותחת את הפרטים.
- **גרירה לסידור** - עם העכבר, או לחיצה ארוכה בנייד. הסדר נשמר ("הסדר שלי").
- **משימות ותתי משימות** - לכל משימה יש לפחות תת-משימה אחת. סטטוס קובעים לתתי המשימות, והסטטוס של המשימה נגזר מהן: אם אחת בעבודה אצלי - המשימה בעבודה אצלי; אחרת אם אחת ממתינה לתגובה - ממתינה; אחרת אם אחת לביצוע - לביצוע; רק כשכולן הושלמו - המשימה הושלמה.
- **ארבעה סטטוסים** - **לביצוע**, **בעבודה אצלי** (מחכה לפעולה שלי), **ממתין לתגובה** (מחכה למישהו אחר), **הושלם**. בשני סטטוסי העבודה מוצג כמה זמן הפריט כבר בהם.
- **קטגוריות עם צבע** - פיתוח, HR, אישי. אפשר להוסיף, לשנות שם, לשנות צבע ולמחוק: שבב "עריכה" בשורת הקטגוריות, או "קטגוריות" בסרגל העליון.
- **דשבורד** - כמה פריטים בכל סטטוס. לחיצה מסננת.
- **סינון, חיפוש ומיון** - "הסדר שלי" כברירת מחדל, או לפי סטטוס (לביצוע, בעבודה אצלי, ממתין לתגובה, הושלם), עדכון, יצירה או קטגוריה.
- **מותאם לנייד** - שתי עמודות ריבועים, כפתור "+" צף, פרטי משימה במסך מלא. אפשר להוסיף למסך הבית.
- **תצוגת דמויות** - במקום ריבועים (בהגדרות): משרד שבו כל משימה היא דמות קטנה ומונפשת - אדם, חתול, פנדה, רובוט או חייזר, כל אחת בלבוש ובמראה משלה. כשהמשימה בעבודה הדמות עובדת בשולחן שלה (מקלידה, מדברת בטלפון, מטאטאת...), ובשאר הזמן היא חיה את חייה: משוטטת, שותה קפה, יושבת על הספה, ישנה כשהמשימה נזנחה ורוקדת כשהיא הושלמה. הדמויות ניגשות זו לזו ומדברות, ויש מסך מלא.
- **היום שלי** - עד 3 תתי משימות להיום, בפס מתחת לדשבורד. מתאפס לבד בבוקר.
- **מה עכשיו?** - הגרלה של תת-משימה פתוחה לעבוד עליה, עם כפתור "יאללה, מתחילים".
- **דוח מצב** - סיכום טקסט של מה בעבודה, ממתין והושלם, להעתקה או לשליחה בווטסאפ ובמייל.
- **חגיגה** - קונפטי (וצליל, אם רוצים) כשמשימה הושלמה.
- **אבק** - משימה שלא נגעו בה שבועות דוהה ומעלה קורי עכביש, עם הצעה לנער אותה או לסגור אותה.
- **ערכות חג** - סביב חגים (לפי הלוח העברי) האפליקציה מקבלת צבעים, דגלונים וברכה, והדמויות מתלבשות.
- **הכתבה קולית** - מיקרופון ליד שדות הטקסט, בעברית (כרום, אדג', ספארי). הקול מעובד בשירות של הדפדפן, ולכן לא כדאי להכתיב מידע רגיש.
- **חוות אייג'נטים** - משימת פיתוח משויכת לפרויקט, וכל תת-משימה שלה נשלחת לאייג'נט שעובד על מחשב הפיתוח: Claude Code עם חשבון העבודה, או Codex עם החשבון האישי. האייג'נט עובד בענף ובתיקייה משלו ומדווח בחזרה, ואפשר לענות לו מהלוח, גם מהנייד. כשהוא עובד תת-המשימה "ממתין לתגובה", וכשהוא מסיים היא "בעבודה אצלי". דורש ראנר שרץ במחשב - מדריך התקנה: `html/agent-farm-setup-guide.html`.
- **ערכה בהירה / כהה**, קיצור `N` למשימה חדשה.

## איפה הנתונים

עם חשבון, המשימות נשמרות בפרויקט Supabase פרטי ומסונכרנות בין כל המכשירים שמחוברים לאותו חשבון. כל חשבון רואה רק את הנתונים שלו (Row Level Security). אפשר לעבוד גם בלי רשת - השינויים יוצאים כשהרשת חוזרת. התנתקות מוחקת את המשימות מהמכשיר (הן נשארות בחשבון).

כשהאתר לא מחובר ל-Supabase הוא עובד במצב מקומי: הנתונים רק בדפדפן, עם ייצוא/ייבוא גיבוי בהגדרות.

## פיתוח

```
npm run serve          # http://localhost:8080
npm test               # בדיקות יחידה
npm run runner:login   # ראנר האייג'נטים: התחברות (פעם אחת)
npm run runner         # ראנר האייג'נטים: הפעלה
```

פריסה: `git push` ל-`main` -> GitHub Actions מריץ בדיקות ומפרסם ל-GitHub Pages. חיבור Supabase: `Kingdom_of_Claudes_Beloved_MDs/DEPLOYMENT.md`.
פרטים טכניים: `TECHNICAL.md`.
