# ניהול משימות

מנהל משימות אישי בעברית: משימות בריבועים שאפשר לגרור ולסדר, תתי משימות, ארבעה סטטוסים, קטגוריות צבעוניות, והתחברות שמסנכרנת בין המחשב לנייד.

**כתובת:** https://tzudbadichi.github.io/task-manager/

## מה יש בו

- **גריד ריבועים** - כל משימה היא ריבוע: הפס העליון בצבע הקטגוריה, והרקע והמסגרת בצבע הסטטוס. בריבוע תצוגה מקדימה של תתי המשימות, ולחיצה פותחת את הפרטים.
- **גרירה לסידור** - עם העכבר, או לחיצה ארוכה בנייד. הסדר נשמר ("הסדר שלי").
- **משימות ותתי משימות** - לכל משימה יש לפחות תת-משימה אחת. סטטוס קובעים לתתי המשימות, והסטטוס של המשימה נגזר מהן: אם אחת בעבודה אצלי - המשימה בעבודה אצלי; אחרת אם אחת ממתינה לתגובה - ממתינה; אחרת אם אחת לביצוע - לביצוע; רק כשכולן הושלמו - המשימה הושלמה.
- **ארבעה סטטוסים** - **לביצוע**, **בעבודה אצלי** (מחכה לפעולה שלי), **ממתין לתגובה** (מחכה למישהו אחר), **הושלם**. בשני סטטוסי העבודה מוצג כמה זמן הפריט כבר בהם.
- **קטגוריות עם צבע** - פיתוח, HR, אישי. אפשר להוסיף, לשנות שם, לשנות צבע ולמחוק: שבב "עריכה" בשורת הקטגוריות, או "קטגוריות" בסרגל העליון.
- **דשבורד** - כמה פריטים בכל סטטוס. לחיצה מסננת.
- **סינון, חיפוש ומיון** - "הסדר שלי" כברירת מחדל, או לפי סטטוס (לביצוע, בעבודה אצלי, ממתין לתגובה, הושלם), עדכון, יצירה או קטגוריה.
- **מותאם לנייד** - שתי עמודות ריבועים, כפתור "+" צף, פרטי משימה במסך מלא. אפשר להוסיף למסך הבית.
- **ערכה בהירה / כהה**, קיצור `N` למשימה חדשה.

## איפה הנתונים

עם חשבון, המשימות נשמרות בפרויקט Supabase פרטי ומסונכרנות בין כל המכשירים שמחוברים לאותו חשבון. כל חשבון רואה רק את הנתונים שלו (Row Level Security). אפשר לעבוד גם בלי רשת - השינויים יוצאים כשהרשת חוזרת. התנתקות מוחקת את המשימות מהמכשיר (הן נשארות בחשבון).

כשהאתר לא מחובר ל-Supabase הוא עובד במצב מקומי: הנתונים רק בדפדפן, עם ייצוא/ייבוא גיבוי בהגדרות.
