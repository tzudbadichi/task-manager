# ניהול משימות

מנהל משימות אישי בעברית: משימות כלליות עם תתי משימות, סטטוסים שמתאימים לעבודה עם תהליכים ברקע ומיילים, וקטגוריות צבעוניות.

**כתובת:** https://tzudbadichi.github.io/task-manager/

## מה יש בו

- **משימות ותתי משימות** - לכל אחת סטטוס משלה, כותרת שנערכת במקום, איש קשר ותיאור.
- **סטטוסים**
  - **לביצוע** / **בעבודה** / **הושלם**
  - **קלוד רץ** - תהליך רץ ברקע. מציג כמה זמן עבר, ואחרי זמן שנקבע (ברירת מחדל 15 דקות) מסמן "לבדוק עכשיו" ויכול לשלוח התראת דפדפן. "בדקתי - עדיין רץ" מאפס את הטיימר.
  - **ממתין למייל** - מחכה לתשובה ממישהו, לא בטיפולך כרגע (מוצג מעומעם). אחרי כמה ימים (ברירת מחדל 3) מוצע "כדאי לתזכר".
  - **התקבל מייל** - הגיעה תשובה, יש משהו שמחכה לך. מודגש בכתום ועולה לראש הרשימה.
- **קטגוריות עם צבע** - פיתוח, HR, אישי, ואפשר להוסיף, לשנות שם וצבע.
- **דשבורד** - כמה מיילים מחכים לך, כמה תהליכי קלוד רצים וכמה צריך לבדוק, כמה ממתינים. לחיצה מסננת.
- **סינון, חיפוש ומיון** - "דחוף קודם" כברירת מחדל.
- **ערכה בהירה / כהה**, מותאם לנייד, קיצור `N` למשימה חדשה.

## איפה הנתונים

הנתונים נשמרים **רק בדפדפן שבו עובדים** (localStorage) ולא נשלחים לשום שרת. כדי לגבות או לעבור מחשב: הגדרות -> ייצוא גיבוי / ייבוא מגיבוי. האפליקציה מזכירה לגבות.
